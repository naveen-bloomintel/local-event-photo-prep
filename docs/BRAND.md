# Local Event Photo Prep brand guide

## Positioning

**Name:** Local Event Photo Prep

**Tagline:** Cull locally. Keep RAWs private. Finish in Lightroom.

**Repository description:** Free, local-first event photo culling and Lightroom
XMP preparation for macOS.

The project should sound practical, trustworthy, and photographer-controlled.
Avoid claiming that automation replaces creative review or that sharpening can
restore genuinely missed focus.

## Core promises

1. Local-first and private: photographs never need to leave the Mac.
2. Non-destructive: the recommended workflow leaves source photographs alone.
3. Photographer-controlled: selections and edits remain reviewable and
   reversible.
4. Lightroom-ready: the output is approved RAW copies plus matching XMP
   sidecars.

## Screenshot rules

- Use only the generated `sample_event/` photographs.
- Replace real home folders with a neutral path such as
  `/Users/you/Pictures/Sample Event`.
- Never show client names, private event names, faces, event databases,
  Lightroom catalogs, credentials, or personal filesystem details.
- Capture the title and key results rather than starting midway down the page.
- Use the Finish screen only as a secondary image demonstrating successful
  Lightroom export.
