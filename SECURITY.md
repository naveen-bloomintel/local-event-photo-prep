# Security Policy

Please do not open a public issue for a vulnerability that could overwrite
photographs, expose local files, or execute untrusted input. Report it privately
to the repository owner through GitHub's private vulnerability reporting.

Local Event Photo Prep is a local desktop workflow. It does not upload
photographs, require credentials, use telemetry, or perform face recognition.
Users should still keep an independent backup and test a release on copied
photographs before using it for a production event.

Do not include private photographs, event names, absolute paths, EXIF serial
numbers, credentials, or generated `_photo_ai` databases in a vulnerability
report. A minimal synthetic reproduction is preferred.

Security fixes are supported on the latest released version.
